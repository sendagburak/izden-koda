# Gereç envanteri

- Geliştirme: Godot **4.7.2 stable**, Compatibility renderer, GDScript. Bu oturumda Godot çalıştırılamadı.
- Android: SDK, platform-tools, JDK, export template ve yerel USB cihaz gerekir.
- Windows/Linux: ilgili export template ve Godot ikilisi gerekir.
- Pardus: `dpkg-deb` ile daha önce export edilmiş Linux oyunu paketlenir; Faz 1 fiziksel test ayrıca gerekir.
- Hiçbir ağ erişimi / reklama / telemetriye ihtiyaç duyulmamalı.
